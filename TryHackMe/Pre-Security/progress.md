# Pre Security — Completed ✅

Completed the TryHackMe Pre Security path, covering foundational cybersecurity 
and networking concepts before moving into hands-on offensive security.

## Topics Covered
- **Networking Basics**: OSI Model, Packets & Frames, Intro to LAN, Extending Your Network
- **How the Web Works**: HTTP in Detail, How Websites Work, Web Application Basics, DNS in Detail
- **Computing Fundamentals**: Inside a Computer System, Computer Types, Operating Systems Introduction, Windows Basics, Virtualisation Basics, Cloud Computing Fundamentals
- **Security Concepts**: CIA Triad, Cryptography Concepts, Data Encoding
- **Programming Basics**: Python Simple Demo, JavaScript Simple Demo, Database SQL Basics
- **Security Mindset**: Become a Hacker, Become a Defender, Defensive Security Intro
- **Career Guidance**: Careers in Cyber, Search Skills, Putting It All Together

## Key Takeaway
This path built the foundational knowledge needed before starting hands-on 
penetration testing — understanding how networks, computers, and the web work 
is essential before learning how to break (and defend) them.
